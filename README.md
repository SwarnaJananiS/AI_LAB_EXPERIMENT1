# AI_LAB_EXPERIMENT1
AI Lab Experiment using Python
Experiment 1: Student Marks, Percentage, Grade and Academic Performance

Aim:
To develop a Python application that accepts student marks, calculates total marks, percentage and grade, and displays academic performance.

Concepts Used:
- Python variables and data types
- Input and output operations
- Arithmetic operators and expressions
- Conditional statements
- Loops

Description:
The program accepts the student's name, number of subjects, and marks for each subject. It calculates the total marks and average percentage, assigns a grade, and displays the student's academic performance.

How to Run:
python experiment1.py

Sample Output
